## Review Focus

1. Declared source pointers must correspond to all actually shipped certifi copies, including the embedded ensurepip wheel; omissions, forged versions and extra declarations fail admission.
2. Wheel member collisions, aliases, encryption, oversized content and ambiguous paths must not bypass source budgets or create files outside the owned build.

4. Source access must remain accurate after admission/copy; changed prepared source, source metadata or notice files must not produce a completed verified candidate.
5. Successful source-access/package checks must leave unrelated native/SDK/owner/hardware/Unity/publication assessment explicitly pending.
