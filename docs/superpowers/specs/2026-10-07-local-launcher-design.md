# Source single-entry local Studio

Parent: [product design](2026-10-06-open-source-product-design.md), M5.1source prerequisite. Preserve React/MediaPipe/Three, existing FastAPI/jobs/media/paired relay and user-installed Blender/Unity. No Electron/Tauri rewrite, binary bundling, public write or license decision in this increment.

After the documented frozen source dependency/Web build setup, one source entry starts the built Studio and existing service on the same **http://127.0.0.1:8787**origin. Windows `start.cmd` and POSIX `start.sh` invoke pinned uv0.12.6/Python3.12.14; developers still need Node24.19.0/npm11.21.0for the initial Web build. The later Windows distribution supplies built Web/runtime without those developer prerequisites.

The launcher binds only127.0.0.1, reserves the requested port before importing the stateful service, never silently selects a different port or stops another process, and opens the system browser only after actual ASGI startup. Missing build, busy port, unreadable startup/configuration and public/private path overlap are explicit failures. Browser opening failure leaves the running service and printed URL usable. Ctrl+C follows the existing owned service shutdown; finally closes only its listener and readiness thread. `--no-browser` supports actual automated local qualification. No default camera/model/cloud operation occurs from launch.

Default server data: Windows `%LOCALAPPDATA%/EmoteCap/data`; non-Windows `${XDG_DATA_HOME:-~/.local/share}/EmoteCap/data`. Data is outside the built Web tree. Browser project storage remains scoped to origin; changing port/browser/address requires a project backup/import for migration. Default source configuration remains repo-root `.env`, selected explicitly with `--env-file` when needed. `--data-dir`, `--web-dir`, `--blender`, `--port` and `--no-browser` are local operator flags, not remote request fields. No API key CLI flag or copying settings/media into source/build.

Add only two opt-in server settings: `EMOTECAP_DATA_DIR` and `EMOTECAP_ENV_FILE`; absent these, the legacy source server keeps existing data/env defaults. The fresh launcher process chooses these before importing main/config. Preserve health/schema/routes/worker/consumer contracts.

Serve only built index and `assets/`, `models/`, `mediapipe/`, `samples/`with permitted static types. Reject dotfiles, traversal, symlinks/junctions and unsupported paths; keep API/file routes ahead of the Studio root. Unknown API paths remain404, not index HTML. MIME for JS/CSS/WASM/task assets must be reliable on Windows. Loopback-only Host protection and anti-framing/no-sniff/referrer headers prevent unintended embedding/content exposure. HTML is not cached across version changes. Private data/config cannot overlap the public root.

Qualification: unit failure/lifecycle/static/security behavior, actual fresh Python process serving the existing health/jobs API plus production Web/model/WASM bytes, and actual Edge sample/edit/native-IDB reload/backup/import on the service itself without Vite/proxy/API mocks. This does not close physical camera/quota, Unity/license/two rigs, laptop, third-party notices, clean-machine or5new-user gates. Keep source changes/test evidence in this existing worktree and preserve earlier scratch.
