# Private video-import measurement collection

M4 offline arithmetic is accepted, but successful saved takes omit failed attempts and timing. Add a private developer collection page and optional import observations to produce actual-source-linked raw attempts, preview packets and final output. This is the video-import path; it does not substitute for Studio camera/laptop FPS, camera-to-display latency, Unity/two rigs or the real before/after quality baseline. No camera or SDK execution is authorized by synthetic verification; real collection requires the existing explicit session SDK choice and the operator's local source declaration/action.

The normal app must retain existing conversion results, two-pass calibration, error/cancellation behavior and SDK admission. Optional observations record source timestamp, seek start, detection start, preview finish, status (ok/no-pose/detector-error/solver-error/seek-error), copied preview frame or null, and assigned hand/tracker status. Every attempted detection, including the tenth fatal failure, is visible. Final calibrated frames are kept separately and are never called timed preview frames. Observer failure disables diagnostics and is explicitly reported; it must not destroy ordinary import work. No default observer or new persistence/upload is introduced.

The shared SDK factory can opt in to report its actual successful pose GPU/CPU delegate without changing the default returned object. Frame detection can opt in to report active/disabled/failed hand tracking, retaining existing default fields/body fallback/permission checks and cleanup. Do not infer GPU from a requested option, active hand tracking from assigned detections, or pose-only metrics as complete finger quality.

The private collector uses existing open/seek/close video, guarded Accurate model setup and actual motion solver/convertVideo. It requires an idle owned video element, selected source≤100MiB/duration≤180seconds, canonical full sourceCommit, bounded environment descriptors, explicit local-processing declaration and SDK authorization. Hash the actual selected File bytes (before inference), record observed source dimensions, current pinned Heavy model hash/SDK version, delegate, requested skeleton/smoothing, and effective hand policy. Permission/cancellation is checked before/after awaited work; close only owned video/model resources including late arrivals. No simultaneous collector job. Raw source video, names, private paths, keys/tokens and landmarks are not embedded in reports.

Record at most21601attempts/32MiB diagnostic JSON and finite monotonic times. Budget, observer, cancellation, seek/detector/final-solver errors preserve a bounded partial raw result with an explicit incomplete reason. Packet projection is allowed only for fully observed attempts, valid≤180second wall interval, warmup shorter than it, and uniform hand policy; hand fallback mid-run must prevent a comparable packet. Completed all-no-person attempts may produce an all-failed packet while final conversion outcome remains no-person. Final saved frames and optional initialization/total conversion timings are separate raw fields. v1 packet duration is detection-to-preview-solver; effectiveFPS uses the full import wall interval, including seeks and final solve. It is not a live camera rate. Set `qualification=pending` throughout.

The private `web/measurements.html` entry is served by developer Vite and is excluded from the default production build. Controls choose File, declared source commit/environment/classification, skeleton/smoothing/warmup, local-processing declaration and the shared default-denied SDK panel, then an explicit Run/Cancel. Granting alone cannot load models/read media. Metadata is frozen per run; withdrawal cancels and invalidates late results. Downloads are explicit raw JSON and, when valid, its preview measurement packet; no automatic save/network/API/IDB. A previous partial/result remains accessible after failure; independent runs get new UUIDs. No diagnostic integration into main Studio UI.

Tests must prove observed/plain import parity, fatal/no-person/solver/seek/dropout paths, observer failure without frame loss, actual fallback metadata, default-denied/no-inference/late owned cleanup, bounded immutable reports and packet rejection on truncation/nonuniform policy. Actual Edge fixture uses an owned synthetic canvas-generated video and mocked SDK only; downloaded valid packet must pass the accepted Python CLI. Do not describe it as real SDK/video quality or hardware proof. Frozen Web/Node/type/build and relevant SDK/capture/browser controls plus one fresh final TypeScript review; one needed Important/Critical TDD correction pass, no rereview/minor polishing. Preserve scratch. No project license/public push/merge/tag/release or new dependency.
