# Starter Rigs

Two original procedural skinned Humanoids with different limb/torso proportions. They use simple authored box geometry and the canonical EmoteCap v2 skeleton; no third-party character mesh, image, recording or animation was downloaded.

Import this sample from Package Manager, then choose **EmoteCap → Create Starter Scene** before entering Play mode. The creator saves Standard/Tall mesh/material/Avatar/prefab assets, the original sample FBX and `StarterScene.unity` under `Assets/EmoteCap/StarterRigs`. Existing destinations reject; modified scenes receive Unity's save prompt. Open the saved scene and press Play. The one visible menu controls Standard; Tall starts the same clip independently.

Actual WindowsUnity6000.5.9f1/Built-in render qualification covers saved dependencies, real FBX direction/scale/timing, both different-proportion rigs, fingers, player lifecycle, mirrored/frozen negative controls and rendered pixels. Other render pipelines/player platforms, physical capture/hardware/new-user acceptance and final whole-plan review remain pending. This is a local unpublished candidate. [Exact animation provenance](Animations/provenance.json) accompanies its three original files.

No camera, MediaPipe processing, Gemini key or Live Link pairing is required. To test your own exports, change that player's Editor Folder to your export directory, enter Play and Refresh. Avoid overlapping menus by testing one player at a time. Leave Play before creating or editing scene assets.

The sample uses the same pending project-license decision as EmoteCap. Dependency wrapper/third-party rights remain separately recorded; original asset authorship does not complete redistribution approval.
